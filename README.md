# BrightPath School Portal: Help Center Project

A customer support portfolio project.
BrightPath is a fictional online school portal for students, parents, and teachers in Nigeria. I created this help center project to document
writing clear support documentation and handling customer tickets.

## What's inside
- 10 help center articles covering common login, fee payment, and account problems
- Macros and ticket examples built in Zendesk (screenshots in /screenshots)

## Skills shown
Technical writing, customer communication, troubleshooting, Zendesk, account security basics
