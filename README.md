# BrightPath School Portal: Help Center Project

A customer support portfolio project. BrightPath is a fictional online school portal
for students, parents and teachers in Nigeria. I created this project to practise
writing clear support documentation and handling customer tickets.

> BrightPath is fictional. This is a learning project, not a real company or client work.
