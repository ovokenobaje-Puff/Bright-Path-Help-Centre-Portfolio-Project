# I can't open or submit my assignment

**What this article helps with:** Fixing problems when an assignment won't open, or when your file won't upload to the BrightPath portal.

## Why this happens

Your work is not lost. Assignment problems usually come from one of these causes:

- The file is too large or in a format the portal does not accept.
- The internet connection dropped during the upload.
- The deadline has passed, so the submit button is locked.
- The browser has old saved data that interferes with the page.

## If you can't open an assignment

1. Log in and click **Assignments** in the main menu.
2. Click the assignment title. Check that it belongs to the right subject and class.
3. If the file will not open, download it and open it on your device instead of in the browser.
4. Make sure you have an app that can open it (for example, a PDF reader for .pdf files or Word for .docx files).
5. Refresh the page, or try a different browser.

## If your file won't upload

1. Check the file type. The portal accepts **PDF, DOC, DOCX, JPG and PNG** files.
2. Check the file size. The limit is **10 MB**. If your file is larger, compress the photos or save a smaller PDF.
3. Rename the file with simple letters and numbers only, for example `Maths-Assignment-1.pdf`. Remove symbols such as `/ & # %`.
4. Check your internet connection. Large files need a stable connection, so avoid uploading on a weak signal.
5. Click **Upload** again and wait until you see the message "Upload successful" before leaving the page.
6. Check that your submission appears in the list with the correct time.

**Quick checks:**

- You are logged in with your own student account.
- The deadline has not passed.
- You are uploading one file at a time.

## If it still doesn't work

- **The submit button is greyed out:** the deadline may have passed. Tell your teacher straight away, and send a screenshot of the page.
- **Error message after uploading:** note the exact message, clear your browser data (cache), and try again.
- **Upload stops or freezes:** try a different network, such as mobile data instead of Wi-Fi, or the BrightPath mobile app.

If none of this works, contact us and include:

- Your full name and class
- Your student ID
- The subject and assignment title
- The file type and size
- A screenshot of any error message

## How to contact support

- **Email:** support@brightpath.example
- **In-portal chat:** click the chat icon at the bottom right of the portal
- **Hours:** Monday to Friday, 8am to 5pm

Please note that support cannot extend a deadline. Only your teacher can do that, so tell them early if you are having trouble.
